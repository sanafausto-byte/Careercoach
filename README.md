# Fausto Sana - Career Coach

Sito web ufficiale di **Fausto Sana**, Career Coach, Orientatore e Formatore professionale accreditato.

## 🚀 Panoramica
- **Tipografia**: Arial Rounded Brand Identity
- **Palette**: Deep Teal (`#0c343d`), Warm Peach (`#f1e1dd`), Warm Terracotta (`#d97736`)
- **Caratteristiche**:
  - Sito statico ultra-veloce a zero dipendenze
  - Responsive per smartphone, tablet e desktop
  - Hub multimediale con player modale YouTube 1-Click
  - Integrazione diretta a Google Calendar per le prenotazioni

## 📂 Struttura del Progetto
- `index.html`: Portale principale (Single-Page e Hub)
- `chi-sono.html`: Profilo, valori e accreditamento
- `servizi.html`: Orientamento, Career Coaching e Formazione
- `collaborazioni.html`: Partner istituzionali e ruoli territoriali
- `risorse.html`: Video, pubblicazioni ASNOR Magazine e slide IA
- `contatti.html`: Agenda Google Calendar e modulo contatti
- `assets/`: Foglio di stile CSS, JavaScript e immagini/loghi HD

## 🌐 Pubblicazione con GitHub Pages
1. Vai su **Settings** > **Pages**
2. Seleziona Source: **Deploy from a branch**
3. Branch: **main** / **root**
4. Salva e attendi 1 minuto per il link pubblico.
